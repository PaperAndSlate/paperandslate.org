# Imagery and Illustration System

## Purpose

Images should make abstract infrastructure tangible without turning the brand into a generic school-supplies theme.

## Core motifs

- layered sheets;
- folded corners;
- slate rectangles;
- document tabs;
- diagrams and relationship lines;
- open books;
- code/editor surfaces;
- archival folders;
- linen folds;
- subtle dry botanical accents used sparingly.

## Project image mapping

| Project | Recommended motif |
|---|---|
| File System | Layered tabbed documents |
| Discovery | A clean manifest sheet with a URL/location cue |
| Organization Schema | Relationship blueprint or organization diagram |
| Course Schema | Catalog cards, structured sheets, or timetable forms |
| Curriculum Standards | Open reference book or mapped framework |
| Tools and Libraries | Dark code/editor surface with restrained context |
| Governance | Charter folio, decision diagram, or public record |
| Documentation | Open manual, sidebar/page system, or indexed books |

## Composition

- use 10–20% breathing space around the focal object;
- align objects on quiet diagonals;
- avoid cluttered desktop scenes;
- preserve crop-safe zones for card ratios;
- use the slate accent as a grounding plane;
- keep paper warm rather than pure white.

## Texture

Photography can show real texture. UI backgrounds use much subtler texture.

## Diagram style

- slate-blue strokes;
- cream or white-paper nodes;
- Inter labels;
- rounded corners 8–12 px;
- no gradients unless communicating a real scale;
- arrows and line semantics explained in a legend;
- text alternative required.

## Illustration sources

Preferred order:

1. custom deterministic diagrams;
2. commissioned or self-produced material still life;
3. carefully reviewed AI-generated material imagery;
4. licensed stock only when specific and authentic.

## Consistency checks

A project card set should match:

- lighting direction;
- color temperature;
- crop density;
- shadow softness;
- texture amount;
- absence of unrelated text.

The mockup media set is under `assets/mockups/media` and can be used as visual direction, not necessarily as final production photography.
