## Forms and controls

Use shadcn/ui primitives as implementation sources for:

- Button
- Input
- Textarea
- Checkbox
- Radio Group
- Select
- Combobox
- Dialog
- Drawer/Sheet
- Tooltip
- Popover
- Tabs
- Accordion
- Table
- Dropdown Menu
- Command
- Toast/Sonner

Paper & Slate should wrap these in semantic components rather than scattering raw primitives across pages.

## Component documentation

Every design-system component should have:

- purpose;
- allowed variants;
- examples;
- accessibility notes;
- responsive behavior;
- content guidance;
- tests;
- status: experimental/stable/deprecated.
