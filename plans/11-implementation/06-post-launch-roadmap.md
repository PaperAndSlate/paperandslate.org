# Post-Launch Roadmap

## First 30 days

- Review search zero-result queries.
- Fix navigation and terminology confusion.
- Collect implementer feedback on first docs.
- Exercise RFC process.
- Publish first project research updates.
- Confirm error and monitoring thresholds.
- Review newsletter demand before enabling segments.

## 30–90 days

Prioritize based on actual project progress:

- schema property explorer;
- client-side JSON/document validation;
- example download library;
- richer project dependency map;
- conformance test documentation;
- contributor onboarding;
- implementation story template.

## 3–6 months

Potential:

- `.well-known` generator;
- secure domain checker after threat model;
- interactive document playground;
- multilingual docs architecture;
- standards mapping explorer;
- version comparison pages;
- public conformance test reports.

## Future Developer Platform

Only after API/auth product design is complete:

- platform repository;
- OpenAPI contract;
- API reference generation;
- authentication and API-key docs;
- status page;
- console design;
- operational SLAs.

## Nonprofit consideration

Formal incorporation may be evaluated when:

- governance extends beyond the founder;
- material funding or contracts exist;
- contributors need institutional continuity;
- trademark and liability ownership require an entity;
- a board can be formed with real responsibilities.

The website architecture already supports reports, funding disclosures, people, and future board information without claiming it prematurely.
