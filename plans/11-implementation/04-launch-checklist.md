# Launch Checklist

## Identity and legal

- [ ] Confirm final public description.
- [ ] Confirm legal-status wording.
- [ ] Review Privacy and Terms.
- [ ] Publish license overview.
- [ ] Publish trademark policy.
- [ ] Publish funding disclosure.
- [ ] Confirm footer copyright/entity wording.
- [ ] Verify no donation/tax claims.

## Governance

- [ ] Charter published.
- [ ] Governance model published.
- [ ] RFC process published.
- [ ] Project lifecycle published.
- [ ] Maintainers published.
- [ ] Contributing guide published.
- [ ] Code of Conduct published.
- [ ] Security policy and private contact work.
- [ ] Conflict policy published.
- [ ] Initial RFCs have accurate status.

## Content

- [ ] Homepage final copy.
- [ ] Foundation pages reviewed.
- [ ] All visible projects have real scope/status.
- [ ] News launch article reviewed.
- [ ] Roadmap updated.
- [ ] People profiles approved.
- [ ] Funding statement accurate.
- [ ] Images licensed and have alt text.
- [ ] No lorem ipsum or invented adoption.
- [ ] Spelling and terminology pass.

## Documentation

- [ ] Docs taxonomy complete.
- [ ] At least one real imported project.
- [ ] Source SHA shown.
- [ ] Version selectors tested.
- [ ] Draft/stable labeling tested.
- [ ] Internal links and anchors pass.
- [ ] Source/edit/report links work.
- [ ] Code examples validate.
- [ ] Print styles checked.
- [ ] `llms.txt` and Markdown output checked.

## Search

- [ ] Typesense production collection provisioned or static provider selected.
- [ ] Search-only key verified.
- [ ] Exact project/property/RFC queries tested.
- [ ] Preview index isolated.
- [ ] Static fallback tested.
- [ ] Zero-result analytics privacy reviewed.

## Newsletter and feeds

- [ ] RSS valid.
- [ ] Atom valid.
- [ ] JSON Feed valid.
- [ ] Feed links in head/footer.
- [ ] Kit enabled or form intentionally disabled.
- [ ] Double opt-in behavior verified.
- [ ] Newsletter privacy language published.
- [ ] Provider failure state tested.

## Accessibility

- [ ] Keyboard test on all templates.
- [ ] Screen-reader test for header, search, docs, newsletter.
- [ ] axe passes.
- [ ] Contrast passes including textured surfaces.
- [ ] 200% zoom and 320 px reflow pass.
- [ ] Reduced motion pass.
- [ ] Accessibility statement published.

## Performance and SEO

- [ ] Lighthouse budgets pass.
- [ ] Core Web Vitals instrumentation active.
- [ ] Bundle report reviewed.
- [ ] Hero and card images optimized.
- [ ] Canonicals verified.
- [ ] Sitemap verified.
- [ ] Robots verified.
- [ ] Preview noindex verified.
- [ ] JSON-LD validated.
- [ ] Open Graph images reviewed.
- [ ] Redirect registry tested.

## Security and operations

- [ ] CSP and headers verified.
- [ ] Dependency scan clear or accepted.
- [ ] SBOM generated when containerized.
- [ ] No secrets in client or repository.
- [ ] GlitchTip configured.
- [ ] Synthetic monitors pass.
- [ ] Health route works.
- [ ] Production rollback tested.
- [ ] Search rollback tested.
- [ ] Incident contacts documented.
- [ ] Domain/TLS verified.

## Final release

- [ ] Content freeze complete.
- [ ] Production deployment SHA recorded.
- [ ] Search index build ID recorded.
- [ ] Smoke tests pass.
- [ ] GitHub READMEs link to canonical site.
- [ ] Launch announcement and feeds publish.
- [ ] Post-launch monitoring window scheduled.
