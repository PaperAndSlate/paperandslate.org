# Content Models

All content models should be validated with Zod during local development, CI, and production builds.

## Project

Required fields:

```ts
interface Project {
  id: string
  slug: string
  name: string
  shortName?: string
  summary: string
  description: string
  type: 'standard' | 'schema' | 'format' | 'tool' | 'library' | 'registry' | 'platform'
  status: 'planned' | 'experimental' | 'draft' | 'candidate' | 'stable' | 'deprecated' | 'archived'
  version?: string
  nextVersion?: string
  repository: string
  docsRoot: string
  maintainers: MaintainerRef[]
  licenses: LicenseRef[]
  lastMeaningfulUpdate: string
  dependencies: string[]
  tags: string[]
  featured: boolean
  visibility: 'public' | 'hidden' | 'preview'
  icon?: string
  image?: string
  links: ProjectLink[]
}
```

## Documentation page

```ts
interface DocsPage {
  title: string
  description: string
  projectId?: string
  versionScope?: string
  docType: 'learn' | 'guide' | 'reference' | 'specification' | 'policy' | 'tutorial'
  normative: boolean
  status?: ProjectStatus
  order?: number
  sourceRepository: string
  sourcePath: string
  sourceRef: string
  sourceSha: string
  editUrl?: string
  aliases?: string[]
  keywords?: string[]
  lastReviewed?: string
  reviewBy?: string
  audience?: Audience[]
}
```

Imported source metadata is generated by the ingestion process, not manually trusted from frontmatter.

## News article

```ts
interface NewsPost {
  title: string
  slug: string
  summary: string
  publishedAt: string
  updatedAt?: string
  status: 'draft' | 'scheduled' | 'published' | 'corrected' | 'withdrawn'
  type: 'announcement' | 'release' | 'project-update' | 'rfc' | 'governance' | 'community' | 'implementation' | 'research' | 'report'
  authors: AuthorRef[]
  projects?: string[]
  rfcIds?: string[]
  tags: string[]
  featured?: boolean
  coverImage?: string
  socialImage?: string
  correction?: Correction
  newsletter?: boolean
}
```

## RFC

```ts
interface RFC {
  number: string
  slug: string
  title: string
  summary: string
  authors: AuthorRef[]
  sponsors?: MaintainerRef[]
  status: 'idea' | 'draft' | 'review' | 'accepted' | 'rejected' | 'withdrawn' | 'superseded' | 'implemented'
  createdAt: string
  updatedAt: string
  reviewStartsAt?: string
  reviewEndsAt?: string
  decisionAt?: string
  affectedProjects: string[]
  targetVersions?: string[]
  discussionUrl: string
  implementationUrls?: string[]
  supersedes?: string[]
  supersededBy?: string
}
```

```ts
interface DecisionRecord {

  status: 'accepted' | 'superseded' | 'reversed'

  relatedRfcs: string[]

  summary: string

  dissent?: string

```

## Person and role

```ts
interface Person {
  id: string
  name: string
  pronouns?: string
  bio: string
  location?: string
  avatar?: string
  links: { label: string; url: string }[]
  roles: {
    title: string
    scope?: string
    startedAt: string
    endedAt?: string
  }[]
}
```

Do not publish email addresses unless the person explicitly chooses to do so.

## Report

```ts
interface AnnualReport {
  year: number
  title: string
  publishedAt: string
  summary: string
  highlights: string[]
  governanceChanges: string[]
  projectReleases: ProjectReleaseRef[]
  contributors: ContributorSummary
  fundingDisclosure: FundingDisclosure

```

## Shared identifiers

All registries use stable lowercase kebab-case IDs. Display names may change without changing the ID.
