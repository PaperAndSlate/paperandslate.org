# Page Template Matrix

## Editorial landing

Used by:

- Homepage
- Foundation
- Governance
- Documentation home

Components:

- eyebrow;
- display headline;
- concise lede;
- primary and secondary actions;
- optional editorial image;
- structured card sections;
- closing newsletter or contribution callout.

## Editorial article

Used by:

- Mission
- Funding
- Reports
- News articles
- Research notes

Components:

- breadcrumb or content type;
- title and deck;
- author/date metadata where appropriate;
- cover image optional;
- readable prose column;
- right rail for contents, related links, or sharing;
- correction history;
- related content.

## Registry index

Used by:

- Projects
- RFCs
- Decisions
- People
- Reports
- Releases

Components:

- title and explanation;
- filters and search;
- status legend;
- featured items optional;
- sortable list or grid;
- empty state;
- pagination only when needed.

## Project detail

Components:

- status, type, and version;
- project headline and purpose;
- primary docs and source actions;
- editorial project image;
- section navigation;
- overview;
- scope and non-goals;
- adoption state;
- release and RFC metadata;
- maintainers and licenses.

## Documentation portal

Components:

- documentation sidebar;
- project selector;
- version selector;
- search;
- quick-start cards;
- popular guides;
- latest releases;
- right contextual rail.

## Documentation content

Components:

- breadcrumbs;
- title, description, status, version;
- draft/stability callout;
- body content;
- code tabs;
- requirement markers;
- tables and property reference;
- in-page contents;
- source actions;
- previous/next links.

## Specification page

Adds:

- normative banner;
- requirement IDs;
- conformance section;
- security and privacy considerations;
- compatibility and versioning;
- formal references;
- change history.

## Schema property page

Adds:

- property path;
- type;
- required/optional;
- cardinality;
- allowed values;
- examples;
- multilingual behavior;
- provenance behavior;
- version introduced/deprecated;
- related properties;
- raw schema link.

## Policy page

Used by:

- Code of Conduct
- Security
- Trademark
- Conflicts
- Licenses
- Privacy

Components:

- policy status and effective date;
- owner;
- review interval;
- version history;
- plain-language summary;
- normative policy text;
- contact route.

## Error and empty templates

Required:

- 404 with search and key routes;
- generic application error;
- documentation source unavailable;
- no search results;
- no projects matching filters;
- planned project with no published docs;
- unsupported historical version;
- newsletter unavailable.
