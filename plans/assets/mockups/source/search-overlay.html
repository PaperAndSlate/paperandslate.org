File System

A human-readable, structured document format for educational content.

Draftv0.1.0Specification
Draft specificationThis project is open for implementation feedback. Breaking changes remain possible before the first stable release.

Overview

Paper & Slate documents use Markdown as the readable foundation and add explicit metadata, blocks, relationships, and extension points where educational content needs more structure.

Core goals

  • Remain understandable as plain text.
  • Represent courses, units, lessons, assessments, and reusable content.
  • Keep teacher-facing and student-facing material connected without conflating them.
  • Support validation, transformation, and long-term migration.
