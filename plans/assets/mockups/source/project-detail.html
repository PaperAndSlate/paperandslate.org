Overview

Readable by people.
Reliable for software.

The format keeps ordinary Markdown approachable while adding explicit structure for educational content. Every advanced capability is opt-in, and a valid document remains understandable when rendered as plain text.

Quick start

---
title: Introduction to Financial Literacy
type: lesson
version: 1.0
---

# Learning objectives

- Explain opportunity cost
- Compare needs and wants

Designed for composition

Courses contain units; units contain lessons; lessons contain reusable blocks. Relationships remain explicit without forcing every document into one monolithic file.
