# Governance

Paper & Slate publishes documentation from a local, reviewable source set. This page records the boundaries that are
currently evidenced by the documentation system; it is not a claim of institutional approval or production status.

## Source review

Central pages are reviewed repository-owned Markdown. Each ingested page retains its source path, local ref, and
content hash. Fixture, sibling-local, and future Git-imported pages remain separated from the reviewed central rendering
path.

## Versions and provenance

Supported and historical versions remain independent records. A content hash identifies the recorded bytes; it is not
presented as a Git commit SHA. Raw Markdown routes remain available for source inspection.

## Honest status

Local checks can establish source shape, route behavior, rendering boundaries, and generated artifacts. They do not by
themselves establish deployment, legal review, provider activation, production monitoring, or factual approval.
