# Provenance

Generated records expose the effective source repository label, relative path, local ref, and SHA-256 content hash. A hash is evidence about these bytes; it is not presented as a Git commit SHA.

## Historical pages

Historical fixture pages use a separate immutable version identifier and never follow the working tree.
